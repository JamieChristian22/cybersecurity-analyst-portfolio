# Capstone Integration

This is the flagship project in my cybersecurity analyst portfolio. It integrates governance and risk, SOC/SIEM monitoring, incident response, vulnerability management, identity and access management, systems/automation, compliance-readiness, and executive reporting into one simulated e-commerce security program.

The case study is designed to show how separate cybersecurity functions connect:

**Business Risk -> Control Ownership -> Architecture -> Monitoring -> Detection -> Incident Response -> Remediation -> Validation -> Executive Reporting**

## Capstone Deliverables

| File | Focus |
|---|---|
| 01 Executive Cybersecurity Program Overview | Business context, top risks, objectives, 90-day outcomes |
| 02 Enterprise Risk & Control Summary | Risk register, control owners, treatment, residual risk, validation |
| 03 Security Architecture & Data Flow | Trust boundaries, application/data flows, monitoring, recovery |
| 04 SOC Detection & Monitoring Plan | P1 logs, detection coverage, ATT&CK, SOC KPIs |
| 05 Incident Response Operating Model | Severity, RACI, lifecycle, escalation, evidence |
| 06 Vulnerability Management Program | Scanning, SLAs, exceptions, retesting, metrics |
| 07 IAM & Access Governance Plan | MFA, RBAC, JML, privileged access, service accounts |
| 08 Compliance & Control Crosswalk | NIST CSF, NIST 800-53, ISO 27001, SOC 2, PCI DSS, GDPR |
| 09 30/60/90-Day Security Roadmap | Owners, dependencies, priorities, measurable success |
| 10 Executive Security Metrics Dashboard | Risk, vulnerability, IAM, SOC, IR, recovery, vendor KPIs |
| 11 Security Program Maturity Review | Current state, target maturity, lessons learned, next steps |
| 12 Recruiter Quick View | Fast hiring-manager summary |
