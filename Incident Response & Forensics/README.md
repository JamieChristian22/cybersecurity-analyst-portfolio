# Incident Response & Forensics

This section demonstrates practical, entry-level incident-response and forensic-analysis skills through simulated investigations, response playbooks, evidence handling, severity classification, MITRE ATT&CK mapping, and post-incident corrective-action work.

The portfolio is structured around an analyst workflow:

**Alert -> Triage -> Evidence -> IOC / Behavior -> Timeline -> Scope -> Severity -> Containment -> Eradication -> Recovery -> Root Cause -> Lessons Learned -> Corrective Actions**
