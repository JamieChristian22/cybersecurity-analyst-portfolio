# Framework Knowledge Matrix

| Framework / Standard | What It Provides | Analyst-Level Application | Portfolio Evidence |
|---|---|---|---|
| NIST Cybersecurity Framework 2.0 | Risk-based cybersecurity outcomes organized around Govern, Identify, Protect, Detect, Respond, Recover | Categorize security activities, identify gaps, communicate risk, connect controls to business outcomes | Security organization model, control checklist, career roadmap |
| NIST SP 800-53 | Detailed catalog of security and privacy controls | Understand control families, map requirements, support evidence collection, identify control gaps | Control assessment methodology and remediation planning |
| CIS Critical Security Controls | Prioritized defensive safeguards | Translate common threats into practical safeguards, prioritize implementation, support hardening discussions | Control checklist and security operations alignment |
| ISO/IEC 27001 | Information Security Management System requirements | Support policy, risk treatment, ownership, governance, and continual improvement | Security organization worksheet and governance mapping |
| COBIT 2019 | Governance and management objectives for enterprise information and technology | Clarify decision rights, accountability, governance structures, and business alignment | Security governance and responsibility model |
| SOC 2 Trust Services Criteria | Criteria for security, availability, processing integrity, confidentiality, and privacy | Organize control evidence, identify readiness gaps, support audit preparation | Compliance checklist and evidence expectations |
| PCI DSS | Security requirements protecting account data environments | Evaluate access, logging, vulnerability, encryption, and incident requirements in payment environments | Compliance checklist control mapping |
| GDPR | EU data protection obligations | Recognize security, privacy, breach-response, accountability, and data-protection considerations | Compliance checklist and governance analysis |

## Practical Use

The purpose of this matrix is not to claim auditor-level mastery of every standard. It demonstrates the ability to understand how frameworks guide real analyst work: organizing security controls, interpreting evidence, identifying gaps, supporting remediation, documenting decisions, and communicating risk to stakeholders.
