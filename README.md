# 🔐 Security Operations Workflow

This portfolio demonstrates an understanding of the full security operations lifecycle:

**1. Identify**

Understand assets, users, systems, vulnerabilities, threats, and business risk.

**2. Protect**

Apply access controls, MFA, least privilege, secure configuration, patching, and security policies.

**3. Detect**

Collect logs, develop detection logic, monitor SIEM alerts, and identify anomalous activity.

**4. Investigate**

Validate alerts, correlate evidence, establish timelines, determine scope, and classify severity.

**5. Respond**

Contain malicious activity, escalate incidents, preserve evidence, and coordinate remediation.

**6. Recover**

Restore trusted operations, validate corrective actions, monitor for recurrence, and document lessons learned.

**7. Improve**

Tune detections, strengthen controls, automate repetitive processes, and track security metrics.
